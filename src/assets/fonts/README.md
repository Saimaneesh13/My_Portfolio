# Local Font Assets

This directory is reserved for offline/local font files (`.woff2`, `.woff`, `.ttf`):
- `Space Grotesk`
- `Inter`
- `JetBrains Mono`

The application defaults to loading these fonts from Google Fonts CDN via preconnect links in `index.html`. If you prefer offline bundling, place font binaries here and import them into `src/index.css`.
