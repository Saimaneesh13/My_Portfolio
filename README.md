## ⚡ Overview

An interactive, spatial **3D WebGL & GLSL Engineering Portfolio** built with **React, TypeScript, Three.js / WebGL shaders, Framer Motion, Tailwind CSS, and Zustand**. Designed to showcase production-grade AI & Machine Learning systems, interactive pipeline simulators, live cloud microservices, and verified engineering credentials.

🔗 **Live Deployment:** [https://my-portfolio-ten-bice-53.vercel.app/](https://my-portfolio-ten-bice-53.vercel.app/)

## ✨ Key Architectural Highlights

- **🧠 Real-Time 3D Particle Core ↔ Portrait Morph (`GLSL Shaders`):** Custom WebGL particle system capable of morphing between an orbital neural core, a 3D particle portrait (with live custom photo upload support), a 3D Neural Brain, and an interactive 3D Curriculum Vitae hologram.
- **🚀 Embedded Live Cloud Workspaces & Simulators:** Inspect system architectures, step through algorithmic execution pipelines, and test live cloud deployments (`Streamlit` & `Render`) or instant in-browser simulators directly inside the **Case Studies** view.
- **🎯 6-Domain Capability Inspector & Full Stack Matrix:** Interactive orbital nodes around a 3D Neural Brain covering AI/ML, Unsupervised NLP, Computer Vision, Programming & Core CS, Backend/Data, and Engineering Leadership.
- **📄 Interactive 3D & Printable Curriculum Vitae:** Switch between the 3D hologram trigger, full-resolution interactive CV sheet, and instant A4 PDF generation.
- **✒️ Custom Luxury 3D UI & Motion Architecture:** Staggered Framer Motion transitions, custom SVG 3D golden fountain pen cursor, and responsive glassmorphic HUD telemetry.
